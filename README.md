# RecipeHub
RecipeHub is a recipe management applictaion. It allows users to store, view, update, delete and scale their recipes. 
## Features
- **Add a recipe**: includes the title, ingredients, cuisine category, serving size and spice level
- **View recipes**: list all recipes, list only the active recipes, and list only the archived recipes
- **Update a recipe**: edit an existing recipe's title, category, and priority
- **Scale a recipe**: scale a recipe's serving size up or down by any number
- **Filter by priority**: retrieve recipes matching a chosen priority level (1–5)

  ## Running the tests
Put this command in the terminal:
  ./gradlew test

The tests cover  all the features: adding, listing (all/active/archived), deleting, updating, scaling, and filtering recipes by priority.
They use both empty and filled in cases.
